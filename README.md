## 🧭 О проекте

**Apartment Value Helper AI** — учебный проект на линейной регрессии, который предсказывает рыночную цену квартиры по её ключевым характеристикам. Идея простая: заложить в модель площадь, расположение и количество комнат — и получить оценку стоимости за секунды.

> 💡 Проект создан как демонстрация базового ML-пайплайна: от чтения данных до оценки качества предсказаний.

---

## ⚙️ Как это работает

```
CSV с данными → обучение модели → предсказание → оценка качества
```

1. Данные о квартирах загружаются из `apartment_data.csv`
2. Выборка делится на обучающую и тестовую части
3. Модель `LinearRegression` обучается на тренировочных данных
4. Для новой квартиры модель выдаёт предсказанную цену
5. Качество модели проверяется через MAE / MSE / RMSE / R²

---

## 🧩 Признаки модели

| Признак | Что означает |
|---|---|
| `factor1_sqrt_m` | Площадь квартиры (м²) |
| `factor2_stepfrommetro` | Расстояние до метро |
| `factor3_nearby_to_center` | Расстояние до центра города |
| `factor4_rooms` | Количество комнат |
| `predict` | Целевая переменная — цена квартиры |

## 💡 Пример использования

```python
from model import ApartmentValModel

apt = ApartmentValModel()
apt.learn_part()
apt.get_error()

print("Средняя ошибка модели (MAE):", apt.mae)

price = apt.predict_new([110, 1000, 3, 6])
print("Предсказанная цена:", price[0])
```

## 📊 Метрики качества

| Метрика | Что показывает |
|---|---|
| **MAE** | Средняя ошибка в рублях — насколько модель ошибается в среднем |
| **MSE** | Квадратичная ошибка — сильнее штрафует крупные промахи |
| **RMSE** | Корень из MSE — ошибка снова в понятных единицах (рублях) |
| **R²** | Насколько хорошо модель объясняет разброс цен (1.0 — идеально) |

> ⚠️ Датасет учебный и небольшой — метрики стоит воспринимать как демонстрацию подхода, а не как статистически надёжную оценку.
